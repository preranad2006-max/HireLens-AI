# HireLens AI

### Explainable & Bias-Aware AI Resume Ranking Platform

HireLens AI helps recruiters quickly identify the most suitable candidates by comparing resumes with a job description and providing transparent, explainable match results.

## 🚀 Live Demo

[HireLens AI – Live Demo](https://hire-lens-ai-pi.vercel.app/)

The application is deployed on Vercel and is ready for evaluation.

## 🚀 Features

- 📄 Upload multiple resumes
- 💼 Enter a job description
- 🤖 AI-assisted resume & job description analysis
- 📊 Candidate match score (0–100)
- 🏆 Automatic candidate ranking
- 🔍 Skill and experience matching
- ❌ Missing skill detection
- 💡 Explainable "Why this candidate?" results
- ⚖️ Bias-aware scoring that avoids sensitive personal attributes
- 🔎 Candidate search and filtering
- 📋 Shortlist suitable candidates

## 🛠️ Tech Stack

- React
- TypeScript

- CSS
- AI/NLP-based matching
- PDF Resume Parsing

## 🧭 Usage

1. Enter or select a Job Description.
2. Upload one or more PDF resumes.
3. Start the analysis.
4. HireLens AI extracts relevant candidate information.
5. The system compares candidates with the job requirements.
6. Candidates receive a match score from 0–100.
7. Candidates are automatically ranked.
8. Review matched skills, missing skills and the "Why this candidate?" explanation.
9. Use search/filtering to explore candidates.
10. Shortlist suitable candidates for further consideration.

 ## 🎯 Hackathon Focus

HireLens AI focuses on accurate, explainable and bias-aware candidate ranking. 
It helps recruiters understand not only who ranks highest, but also why.

## 💡 Key Innovation

HireLens AI goes beyond simple keyword matching by providing explainable candidate ranking.

For every candidate, recruiters can see:
- Why the candidate received the score
- Matched and missing skills
- Relevant experience and projects
- Evidence-based ranking
- Bias-aware scoring that avoids sensitive personal attributes

This makes the recruitment process more transparent, consistent, and easier to understand.

## Problem & Solution

### Problem
Recruiters often need to review many resumes against a single job description, making manual screening slow and difficult to explain consistently.

### Solution
HireLens AI automatically analyzes resumes against job requirements, extracts relevant candidate information, calculates match scores, ranks candidates, identifies missing skills, and provides an explainable “Why this candidate?” result.

The platform focuses on skill and experience relevance while avoiding sensitive personal attributes in candidate scoring.
